## 國泰世華銀行自動登錄
### 問題與解決方案
1. **Python 每次執行都會開新視窗** → 使用文件監聽方式（/tmp/captcha.txt）
2. **驗證碼會刷新** → 必須在同一個瀏覽器視窗操作
3. **Discord 圖片傳送** → 用 peekaboo 截圖 + openclaw message send

### 最終流程
1. Python 腳本填入身份證、出生年月日、勾選
2. 持續監聽 /tmp/captcha.txt 文件
3. 用 peekaboo 截圖傳到 Discord
4. 用戶回覆驗證碼 + 刷新時間 + 關鍵字
5. 寫入文件觸發腳本

- 監聽腳本：`/Users/wuxiaoyin/.openclaw/workspace/cathay_rush.py`

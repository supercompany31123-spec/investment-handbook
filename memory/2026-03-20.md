## 重要原則更新 (09:48)

### 表格資訊呈現方式

當需要傳送「表格類」的資訊時，必須選擇以下其中一種方式：

1. **Excel 表格**：做成 .xlsx 檔案寄送
2. **手機好讀版**：用清晰的文字表格呈現（不使用 Markdown 表格，改用以下格式）：

```
| 項目 | 內容 |
|-----|------|
| 欄位1 | 內容1 |
| 欄位2 | 內容2 |
```

或用 bullet list 方式呈現，保持手機可讀性。

**不要用**：複雜的 Markdown 表格或過長的文字敘述。
